# Lab7Web_PHP — Pemrograman Server-Side dengan PHP

Repositori ini dibuat untuk memenuhi tugas Praktikum Pemrograman Web mengenai **Pemrograman Server-Side dengan PHP**, mencakup penggunaan variabel, operator, percabangan, perulangan, array, function, pemrosesan form GET & POST, serta validasi dan sanitasi input.

---

## 📋 Tujuan Praktikum
1. Memahami perbedaan pemrosesan *client-side* dan *server-side*.
2. Mengenali sintaks PHP dan menjalankan file PHP melalui server lokal (XAMPP).
3. Menggunakan variabel, tipe data, operator, percabangan, perulangan, dan *function*.
4. Menerima dan memproses data *form* menggunakan metode `GET` dan `POST`.
5. Melakukan validasi dan sanitasi input sebelum data ditampilkan atau diproses.
6. Membangun aplikasi sederhana yang menerima, memproses, dan menampilkan data pengguna secara aman.

---

## 💻 Perangkat yang Digunakan
* **Web Server Lokal:** XAMPP (Apache / PHP 8.2.12)
* **Code Editor:** Visual Studio Code
* **Browser:** Google Chrome
* **Version Control:** Git & GitHub

---

## 🚀 Cara Menjalankan Server Lokal
1. Buka **XAMPP Control Panel**.
2. Klik tombol **Start** pada bagian **Apache** hingga statusnya berubah menjadi warna hijau.
3. Pastikan folder proyek **`Lab7Web_PHP`** sudah disalin ke dalam direktori `C:\xampp_new\htdocs\` (atau direktori `htdocs` XAMPP di komputer Anda).
4. Buka browser Google Chrome, lalu akses latihan melalui tautan berikut:

* **Latihan 1:** `http://localhost/Lab7Web_PHP/latihan1/`
* **Latihan 2:** `http://localhost/Lab7Web_PHP/latihan2/`
* **Latihan 3:** `http://localhost/Lab7Web_PHP/latihan3/`
* **Latihan 4:** `http://localhost/Lab7Web_PHP/latihan4/`
* **Latihan 5:** `http://localhost/Lab7Web_PHP/latihan5/cari.php`
* **Latihan 6:** `http://localhost/Lab7Web_PHP/latihan6/`
* **Latihan 7:** `http://localhost/Lab7Web_PHP/latihan7/`
* **Mini Project:** `http://localhost/Lab7Web_PHP/mini_project/`
