# Lab7Web_PHP — Praktikum 7

## Tujuan
Mempelajari PHP server-side, variabel, operator, percabangan, perulangan, array, function, form GET/POST, validasi, sanitasi, dan pengolahan data.

## Perangkat
- Laptop/PC Windows
- XAMPP (Apache dan PHP)
- Visual Studio Code
- Browser (Chrome/Edge)

## Cara menjalankan
1. Instal XAMPP.
2. Buka XAMPP Control Panel, klik **Start** pada Apache.
3. Salin folder `Lab7Web_PHP` ke `C:\xampp\htdocs\`.
4. Buka VS Code, pilih File > Open Folder, lalu buka folder tersebut.
5. Akses halaman berikut melalui browser:
   - `http://localhost/Lab7Web_PHP/latihan1/`
   - `http://localhost/Lab7Web_PHP/latihan2/`
   - `http://localhost/Lab7Web_PHP/latihan3/`
   - `http://localhost/Lab7Web_PHP/latihan4/`
   - `http://localhost/Lab7Web_PHP/latihan5/cari.php`
   - `http://localhost/Lab7Web_PHP/latihan6/`
   - `http://localhost/Lab7Web_PHP/latihan7/`
   - `http://localhost/Lab7Web_PHP/mini_project/`

## Struktur folder
Setiap latihan mempunyai file PHP tersendiri. Mini project berada di folder `mini_project`.

## Pengujian
Lakukan pengujian input valid dan tidak valid. Ambil screenshot browser untuk setiap latihan, hasil mini project yang berhasil, serta pesan validasi. Simpan gambar pada folder `screenshots/`.

## Catatan
Mini project menerapkan validasi NIM 9 digit sebagai ketentuan tambahan yang ditetapkan pada implementasi ini. Sesuaikan jika dosen menentukan panjang NIM yang berbeda.
